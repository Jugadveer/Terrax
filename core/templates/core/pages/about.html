About

Terrax started from a simple complaint: property listings tell you what a place looks like and almost nothing about whether the paperwork is in order.

Most property portals are advertising. The listing exists to get you to call an agent, so it carries photographs, a price, and as little else as the seller can get away with. Whether the title is clean, whether the tax is paid, whether the asking price bears any relation to what similar places sell for: all of that happens later, in private, after you have already spent time on it.

Terrax inverts the order. A listing cannot go live without its title deed, a tax receipt and a utility bill. Those files are checked as they arrive, and the result of the check is shown to buyers rather than kept internally. Every listing carries a valuation calculated from comparable properties, with the comparables on the page. Every listing carries a risk score, with the factors that produced it on the page.

None of it is magic, and none of the numbers come from a language model. The valuation is a weighted comparison, written out in plain Python, and you can read the working on any listing.

Three decisions worth explaining

The language model never decides a number

Every figure on the site comes from code you can read. When a model is configured, it is handed the finished valuation and asked to explain it in plain language, with an explicit instruction not to state a different figure. With no model configured, the explanation is assembled from the same data and the site behaves identically. Which one produced the text is printed under it.

Nothing renders from a placeholder

Every count, price and chart on this site is a database read. An empty deployment shows zeroes and empty states, not invented traction. That sounds obvious, and it is the single most common thing a demonstration gets wrong.

Ownership checks are queries, not conditionals

A listing you do not own is not loaded and then refused; it is filtered out of the query by owner before it is ever fetched. The same is true of offers, which are scoped to the two parties. There is no code path that holds someone else's row and decides whether to allow it.
